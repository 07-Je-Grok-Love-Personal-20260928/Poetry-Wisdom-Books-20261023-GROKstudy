## 📏 引用原则
- 信条和信经的文字逐字取自 [ccifellowship.org](https://ccifellowship.org/)。生成页面时，程序会检查每段摘录的起止文字确实存在于原文中。
- 经文取自和合本（新标点），通过信望爱站 API 获取。v1.1.0 起，`tools/vcheck.py` 会把全站带出处的短引语（经文卡、表格、行内引语、口诀、测验、信条对照）逐一与和合本核对，结果写入 `tools/vcheck_report.json`。
- 威斯敏斯特标准（WCF/WLC/WSC）逐字取自 [RTF-USA《威斯敏斯特标准》简体中文新版（贾少彬 译，2024）](https://rtf-usa.com/wp-content/uploads/2024/08/RTF-Westminster-Standards-FINAL-DIGITAL.pdf)，每段注明 PDF 页码。`src/wm.py` 在生成页面时与 PDF 文本逐字核对，未通过核对的段落（WSC 4、WLC 109）不作引用。
- 引号用法：“……”加出处＝逐字引文；「……」或标注“意译／概括／本站译”＝转述。
- 其他改革宗机构的资料只作概述并附链接，不作原文引用。

## 🛠 技术
纯静态网站，所有资源都在本地，没有外部 CDN。由 Python 生成器（`src/build.py`）输出到 `docs/`。采用玻璃拟态设计，支持响应式与全宽布局，有可折叠目录、全站搜索、明暗主题，地图为 SVG（Natural Earth）。
已用 Playwright 在 390、768、1440 px 三种宽度下检查全部页面，均无横向溢出。
