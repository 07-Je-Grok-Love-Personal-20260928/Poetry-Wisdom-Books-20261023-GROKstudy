## ✨ v4.0.0 更新说明（2026-11-19）
- **新分页「💗 爱上诗篇」**（`psalms-love.html`）：W. 罗伯特·戈弗雷《爱上诗篇》（乔兰山以妲 译）全书 49 章逐章导读——
  - 导论八章：诗篇的四种魅力、诗114 示范、五个难点、循环主题、说话者（大卫 → 基督 → 我们）、诗歌形式（平行、中心句、交叉、离合诗）、五卷大结构、读诗十问；
  - 五卷书各有总论和原书大纲，以及 30 章重点诗篇默想（共 32 篇：3、8、18、21、22、30、46、48、51、68、69、72、73、74、78、81、86–89、90、92、95、103、104、106、109、110、118、121、135、138）的要点、指向基督与应用；
  - 结论：诗146–150 逐一对应五卷；后记；
  - 每章附原书「默想与讨论」题目（共 144 题，可折叠）；五卷「阶梯」动画图、五卷篇数柱状图、主题思维导图、读诗三步流程图；口诀「信 · 委 · 危 · 慰 · 庆」；翻卡与测验。
- **新分页「🏡 家庭灵修」**（`psalms-devotional.html`）：Peter H. Holtvlüwer《家庭灵修·诗篇》（2018）366 天全部篇目——诗篇 1–150 共 310 天（每篇一句本站概括的核心），附录一 基督传道生涯 37 天（时间线视图）、附录二 节令 15 天、附录三 圣餐 4 天；每天列出题目、经文、对读经文和和合本钥节；可勾选「已读」，进度保存在本机。
- **信条对照**：两页都有「改革宗信条对照与评注」，标出与三项联合信条一致之处，以及解释性观点（五卷主题编排）、唱诗篇、咒诅诗、守护天使、节令等需要说明之处。

## 📏 引用原则
- 信条和信经的文字逐字取自 [ccifellowship.org](https://ccifellowship.org/)。生成页面时，程序会检查每段摘录的起止文字确实存在于原文中。
- 经文取自和合本（新标点），通过信望爱站 API 获取。v1.1.0 起，`tools/vcheck.py` 会把全站带出处的短引语（经文卡、表格、行内引语、口诀、测验、信条对照）逐一与和合本核对，结果写入 `tools/vcheck_report.json`。
- 威斯敏斯特标准（WCF/WLC/WSC）逐字取自 [RTF-USA《威斯敏斯特标准》简体中文新版（贾少彬 译，2024）](https://rtf-usa.com/wp-content/uploads/2024/08/RTF-Westminster-Standards-FINAL-DIGITAL.pdf)，每段注明 PDF 页码。`src/wm.py` 在生成页面时与 PDF 文本逐字核对，未通过核对的段落（WSC 4、WLC 109）不作引用。
- 引号用法：“……”加出处＝逐字引文；「……」或标注“意译／概括／本站译”＝转述。
- 其他改革宗机构的资料只作概述并附链接，不作原文引用。

## 🛠 技术
纯静态网站，由 Python 生成器（`src/build.py`）输出到 `docs/`。除了实时地图的瓦片图片，所有资源都在本地，没有外部 CDN；Leaflet 1.9.4（BSD-2）打包在 `docs/assets/vendor/leaflet/`。采用玻璃拟态设计，支持响应式与全宽布局，有三级可折叠、可拖宽的目录、全站搜索、明暗主题。
检查工具：`tools/vcheck.py`（经文逐字核对）、`tools/qa2.py`（多宽度版面检查，截图保存在 `qa/`）、`tools/scrollperf.py`（移动端滚动性能）。
