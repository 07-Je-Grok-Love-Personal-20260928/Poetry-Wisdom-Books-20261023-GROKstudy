## 📚 内容（12 页）
1. **首页**：五卷一览、学习路径（本机记录进度）、颜色图例
2. **整本圣经视角**：正典（BC 4–6）、圣经神学五幕、圣约表、时间线、总地图、智慧与敬畏、希伯来诗歌
3–7. **约伯记 / 诗篇 / 箴言 / 传道书 / 雅歌**：每卷包括一览、整本圣经中的位置、圣约、时间线、地理（SVG 地图）、历史与古代近东文化、写作目的、结构（图表/思维导图）、神学主题、难点、信条对照、多种观点、应用、速记与测验
8. **信条对照**：三项联合信条中引用五卷书的全部 111 处脚注（逐字原文，并突出显示脚注）
9. **三大信经背诵版**：使徒信经、尼西亚信经、亚他那修信经（逐字 CCI），有遮盖、提示和朗读工具
10. **信经对比**：异同、并列对照、所针对的异端、大公会议地图、为什么需要三份信经
11. **速记中心**：五卷总表、全部口诀、20 张钥节卡、综合测验、30 天计划
12. **来源与方法**

## 📏 引用原则
- 信条和信经的文字逐字取自 [ccifellowship.org](https://ccifellowship.org/)。生成页面时，程序会检查每段摘录的起止文字确实存在于原文中。
- 经文取自和合本（新标点），通过信望爱站 API 获取。
- 威斯敏斯特标准和其他改革宗机构的资料只作概述并附链接，不作原文引用。

## 🛠 技术
纯静态网站，所有资源都在本地，没有外部 CDN。由 Python 生成器（`src/build.py`）输出到 `docs/`。采用玻璃拟态设计，支持响应式与全宽布局，有可折叠目录、全站搜索、明暗主题，地图为 SVG（Natural Earth）。
已用 Playwright 在 390、768、1440 px 三种宽度下检查全部页面，均无横向溢出。
