    🤝为什么先看整本圣经？

    🌱
    创造神借智慧创造世界（箴3:19；8:22–31）
    🐍
    堕落虚空与咒诅（传1:2；罗8:20）
    🤝
    圣约敬畏耶和华的百姓（诗25:14）
    👑
    基督神的智慧与受膏君王（林前1:24；诗2）
    🌅
    成全新天新地，婚筵（启19:7；21:1）

    诗歌智慧书不是零散的格言和诗歌，而是圣约百姓在创造—堕落—救赎—成全的历史中如何受苦、祷告、生活、思考和相爱的书。→ 先读“整本圣经视角”
